# SwiftFix Service

SwiftFix Service is a full-stack service booking platform with login, registration, profile management, and responsive UI.

## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL

---

# How to Run Project

## Step 1: Download Project
Download or clone this repository.

## Step 2: Move Folder
Move project folder into:

```bash
htdocs
```

Example:

```bash
C:\xampp\htdocs\
```

## Step 3: Start XAMPP
Start:
- Apache
- MySQL

## Step 4: Create Database
Open phpMyAdmin.

Create database named:

```bash
register2
```

## Step 5: Configure Database
Open:

```bash
con.php
```

Add your database username and password if needed.

## Step 6: Run Project
Open browser and type:

```bash
http://localhost/SwiftFix-Service
```
